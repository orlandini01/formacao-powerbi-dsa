# Capítulo 11 — Estatística Fundamental Para Data Science

## 📌 Sobre o capítulo
Capítulo teórico, sem laboratório prático de Power BI, dedicado aos fundamentos de Estatística aplicados à Data Science — base essencial para interpretar dados corretamente antes de qualquer análise ou modelagem.

## 🧠 O que eu aprendi
- Definição de Estatística e sua relação com Data Science
- Diferença (e semelhanças) entre Estatística e Data Science
- Áreas onde a Estatística é aplicada e suas principais subáreas
- Estatística Descritiva x Estatística Inferencial
- O que é Big Data Analytics
- Diferença entre População e Amostra
- Técnicas de Amostragem
- Diferença entre Parâmetro e Estatística
- Dados Primários x Dados Secundários
- Diferença entre Observações e Variáveis
- Tipos de Variáveis (qualitativas e quantitativas)
- Medidas de Posição: Média, Mediana e Moda
- Medidas de Dispersão: Variância e Desvio Padrão
- Coeficiente de Variação
- Medidas de Posição Relativa: Percentis, Quartis e Escore Z
- Métodos estatísticos aplicados à análise de dados

## 🎯 Principais conceitos e ferramentas
- Estatística Descritiva e Inferencial
- Amostragem e representatividade de dados
- Medidas de tendência central (média, mediana, moda)
- Medidas de dispersão (variância, desvio padrão, coeficiente de variação)
- Percentis, quartis e escore Z
