# Capítulo 08 — Power BI Para Análise de Dados Financeiros

## 📌 Sobre o capítulo
Capítulo dedicado à área Financeira, com o Mini-Projeto 5: construção de um dashboard de análise financeira, cobrindo desde a correção de layout até a criação de segmentos de receitas e despesas.

## 🧠 O que eu aprendi
- Qual a função da área de Finanças dentro de uma empresa
- Principais KPIs da área de Finanças
- Principais tipos de despesas de uma empresa
- Principais tipos de receitas de uma empresa
- Como identificar e corrigir problemas de layout ao carregar os dados no Power BI
- Como fazer pivot de tabela no Power BI
- Como criar hierarquia de data no Power BI
- Como estruturar uma tabela de medidas com indicadores financeiros
- Como criar uma tabela de sumário financeiro

## 🛠️ Mini-Projeto 5 — Dashboard de Análise Financeira
Construção do dashboard, cobrindo:
- Carregamento dos dados e identificação de problemas de layout
- Pivot de tabela
- Criação da hierarquia de data
- Tabela de medidas com indicadores financeiros (2 partes)
- Total de receitas por componente
- Total de despesas por componente e linha média
- Tabela de sumário financeiro
- Criação dos principais segmentos de receitas e despesas (2 partes)
- Versão final do dashboard

## 🎯 Principais conceitos e ferramentas
- KPIs Financeiros (receitas e despesas)
- Pivot de tabela no Power Query
- Hierarquia de datas
- Tabela de medidas e tabela de sumário
- Segmentação de receitas e despesas por componente
