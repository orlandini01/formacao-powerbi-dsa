# Capítulo 10 — Power BI Para Análise de Dados do Mercado de Ações

## 📌 Sobre o capítulo
Capítulo marco: fecha a metade do curso e traz o Mini-Projeto 6, com foco no Mercado de Ações. Aborda Time Intelligence no Power BI e o uso de Narrativa Inteligente para explicar automaticamente os resultados do dashboard.

## 🧠 O que eu aprendi
- O que é o Mercado de Ações
- Como interpretar dados do Mercado de Ações
- Onde e como extrair dados reais para construir um portfólio de projetos
- Como resolver problemas de tipo de dado "Data" no Power BI
- Como usar Time Intelligence no Power BI para análises temporais
- Como calcular variação Month-over-Month (MoM) da média de fechamento
- Como incluir Narrativa Inteligente no dashboard
- Como adicionar segmentação de dados a um dashboard já finalizado

## 🛠️ Mini-Projeto 6 — Dashboard Analítico do Mercado de Ações com Narrativa Inteligente
Construção do dashboard, cobrindo:
- Extração de dados reais do mercado de ações
- Carregamento dos dados no Power BI
- Correção de problema de tipo de dado (Data)
- Total do volume negociado de ações ao longo do tempo
- Tabela de valores médios por mês
- Time Intelligence no Power BI (2 partes)
- Variação da média de fechamento Month-over-Month (MoM)
- Inclusão de Narrativa Inteligente no dashboard
- Adição de segmentação de dados
- Versão final do dashboard

## 🎯 Principais conceitos e ferramentas
- Interpretação de dados do mercado financeiro/ações
- Extração de dados reais (dados abertos de mercado)
- Time Intelligence (funções de inteligência de tempo no DAX)
- Cálculo de variação MoM (Month-over-Month)
- Narrativa Inteligente (Smart Narrative)
- Segmentação de dados (slicers)
