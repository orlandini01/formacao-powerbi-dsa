# Capítulo 05 — Power BI Para Análise de Dados Comerciais

## 📌 Sobre o capítulo
Capítulo dedicado à área Comercial, com o Mini-Projeto 2: construção de um dashboard completo de performance de vendas, partindo de dados carregados do Excel até um dashboard com menu de navegação entre relatórios.

## 🧠 O que eu aprendi
- O que a área Comercial representa para uma empresa
- Principais KPIs da área Comercial
- Como carregar dados no Power BI a partir do Microsoft Excel
- Como definir a estrutura dos relatórios de um dashboard antes de construí-lo
- Como usar narrativas inteligentes (smart narrative) para extrair insights automaticamente dos dados
- Como identificar os principais influenciadores de vendas com o visual Key Influencers
- Como criar um menu de navegação entre páginas dentro do próprio dashboard

## 🛠️ Mini-Projeto 2 — Dashboard Comercial: Performance de Vendas
Construção de um dashboard de vendas, cobrindo:
- Carregamento dos dados a partir do Excel
- Exploração inicial dos dados comerciais
- Definição da estrutura dos relatórios do dashboard
- Total de venda por segmento (gráfico de pizza)
- Total de venda por fabricante (gráfico de barras)
- Total de venda por categoria (gráfico de funil)
- Extração de insights com narrativa inteligente
- Análise dos principais influenciadores de vendas
- Total de venda por categoria e ponto de venda (gráfico de faixas)
- Performance por vendedor e região (visual de mapa)
- Menu de navegação para os relatórios do dashboard

## 🎯 Principais conceitos e ferramentas
- KPIs da área Comercial
- Conexão com dados do Excel
- Visuais: pizza, barras, funil, faixas e mapa
- Narrativa inteligente (Smart Narrative)
- Key Influencers (principais influenciadores)
- Navegação por menu dentro do dashboard (bookmarks/botões)
