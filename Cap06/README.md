# Capítulo 06 — Power BI Para Análise de Dados de Recursos Humanos

## 📌 Sobre o capítulo
Capítulo dedicado à área de Recursos Humanos, com o Mini-Projeto 3: análise de dados de RH, cobrindo criação de medidas com DAX, colunas condicionais e formatação avançada de dashboard.

## 🧠 O que eu aprendi
- Qual a função da área de Recursos Humanos dentro de uma empresa
- Principais KPIs da área de Recursos Humanos
- Como carregar dados no Power BI a partir de arquivo CSV
- Como criar uma tabela de medidas (measures table) no Power BI
- Funções DAX: `COUNTROWS`, `CALCULATE`, `DIVIDE` e `AVERAGE`
- Como criar colunas condicionais no Power BI
- Como criar medidas com DAX a partir de uma coluna condicional
- Substituição de valores para tratar dados
- Formatação avançada: títulos, textos, legendas, eixos, rótulos de detalhe e transparência

## 🛠️ Mini-Projeto 3 — Análise de Dados de RH com Power BI
Construção do dashboard, cobrindo:
- Carregamento dos dados (CSV)
- Criação da tabela de medidas
- Medidas com DAX: COUNTROWS + CALCULATE, DIVIDE, AVERAGE
- Criação de coluna condicional
- Medida com DAX a partir da coluna condicional
- Total de funcionários por função (gráfico de barras horizontais)
- Percentual de funcionários disponíveis para hora extra (gráfico de pizza, com substituição de valores)
- Percentual de funcionários por nível de envolvimento no trabalho (gráfico de rosca, com coluna condicional)
- Customização de valores percentuais
- Formatação de títulos, textos, legendas, eixos e rótulos de detalhe
- Formatação final do dashboard com customização via transparência

## 🎯 Principais conceitos e ferramentas
- KPIs de Recursos Humanos
- Tabela de medidas dedicada
- DAX: COUNTROWS, CALCULATE, DIVIDE, AVERAGE
- Colunas condicionais
- Visuais: barras horizontais, pizza e rosca (donut)
- Formatação avançada de dashboard (transparência, legendas, eixos, rótulos)
