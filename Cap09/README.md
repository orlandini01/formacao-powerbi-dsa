# Capítulo 09 — Power BI Para Análise de Dados Contábeis

## 📌 Sobre o capítulo
Capítulo dedicado à área de Ciências Contábeis, com o Lab 3: construção de um Balanço Patrimonial usando o visual de Matriz no Power BI, incluindo navegação hierárquica com drill-up e drill-down.

## 🧠 O que eu aprendi
- O que são Ciências Contábeis
- Os principais relatórios usados em Ciências Contábeis
- O que é um Balanço Patrimonial
- Como carregar dados contábeis e o plano de contas no Power BI
- Como construir um Balanço Patrimonial usando o visual de Matriz
- Como ajustar e customizar o visual de Matriz
- Como navegar pela hierarquia de dados com Drill-Up e Drill-Down
- Como habilitar a navegação com Drill Down
- Como alterar o layout de nível dentro de uma matriz
- Como inserir gráfico de barras dentro do visual de Matriz

## 🛠️ Lab 3 — Balanço Patrimonial com Visual de Matriz no Power BI
Construção do dashboard, cobrindo:
- Carregamento dos dados contábeis e plano de contas
- Construção do Balanço Patrimonial
- Ajuste do visual de Matriz (2 partes)
- Navegação pela hierarquia (Drill-Up e Drill-Down)
- Habilitação da navegação com Drill Down
- Alteração do layout de nível
- Gráfico de barras no visual de Matriz
- Finalização do Balanço Patrimonial

## 🎯 Principais conceitos e ferramentas
- Conceitos contábeis: relatórios contábeis e Balanço Patrimonial
- Visual de Matriz no Power BI
- Hierarquias com Drill-Up / Drill-Down
- Customização de layout de nível em matrizes
- Gráfico de barras embutido em visual de matriz
