# Capítulo 17 — Machine Learning e Power BI Para Detecção de Anomalias

## 📌 Sobre o capítulo
Capítulo focado em Detecção de Anomalias usando a linguagem R integrada ao Power BI, aplicada a um caso de transações financeiras, com aprendizado não supervisionado.

## 🧠 O que eu aprendi
- O que é Detecção de Anomalias
- Principais áreas de aplicação da Detecção de Anomalias
- Como instalar R, RTools e RStudio no Windows
- Como customizar o RStudio
- Como instalar pacotes R para detecção de anomalias, manipulação e visualização de dados
- Como carregar dados históricos com Linguagem R
- O que é Aprendizado Não Supervisionado e como aplicá-lo em detecção de anomalias
- Como construir um modelo de Machine Learning para detecção de anomalias com R
- Como fazer previsões com o modelo treinado
- Como definir o Score de Anomalia
- Como aplicar o modelo de detecção de anomalias a novos dados
- Como analisar anomalias usando Box Plot, tanto em R quanto no Power BI
