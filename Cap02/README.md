# Capítulo 02 — Introdução ao Power BI

## 📌 Sobre o capítulo
Primeiro contato com o Power BI: apresentação da ferramenta, instalação do Power BI Desktop e exploração da interface. O capítulo fecha com um laboratório prático de construção de um dashboard analítico de vendas globais.

## 🧠 O que eu aprendi
- O que é a "família" Power BI (Desktop, Service, Mobile) e o papel de cada componente
- Como baixar e instalar o Power BI Desktop
- Navegação pela interface: área de fontes de dados, Power Query, painel de visuais e opções/configurações gerais
- Boas práticas de organização de pastas de trabalho antes de iniciar um projeto no Power BI

## 🛠️ Laboratório Prático 1 — Dashboard Analítico de Vendas Globais
Construção de um dashboard do zero, cobrindo:
- Carregamento da fonte de dados
- Cartão de métricas (KPI cards)
- Gráfico de pizza
- Gráfico de barras empilhadas
- Gráfico de barras horizontais
- Mapa mundial (visual geográfico)
- Aplicação de filtros
- Segmentações de dados (slicers)
- Formatação final: títulos, imagens e estilos visuais

## 🎯 Principais conceitos e ferramentas
- Power BI Desktop
- Power Query (primeiro contato)
- Visuais nativos do Power BI (cartão, pizza, barras, mapa)
- Filtros e segmentações de dados
