# Capítulo 15 — SQL Analytics

## 📌 Sobre o capítulo
Capítulo dedicado à Linguagem SQL, desde os fundamentos até o uso combinado com o Power BI. Cobre a base necessária para consultar, filtrar, agregar e manipular dados diretamente em um banco de dados.

## 🧠 O que eu aprendi
- O que é SQL Analytics e o que seria estudado neste módulo
- Como preparar um banco de dados e a ferramenta de conexão para estudar SQL
- Como conectar ao banco de dados e executar a primeira query
- `SELECT` (2 partes) — seleção de colunas e dados
- `LIMIT` — limitar o número de resultados
- `DISTINCT` — remover duplicidades dos resultados
- Cláusula `WHERE` — filtragem de dados
- Operadores de comparação e operadores lógicos
- `BETWEEN`, `LIKE` e `IN` — filtros específicos de intervalo, padrão de texto e lista de valores
- `ORDER BY` — ordenação dos resultados
- Funções agregadas: `MIN`, `MAX`, `AVG`, `COUNT`, `SUM`
- `GROUP BY` — agrupamento de dados
- `JOIN` (2 partes) — combinação de tabelas
- `INSERT`, `UPDATE` e `DELETE` — manipulação de dados (DML)
- Como usar SQL Analytics dentro do Power BI

## 🎯 Principais conceitos e ferramentas
- Linguagem SQL (DQL e DML)
- Filtros, ordenação e agregações em SQL
- Junção de tabelas com JOIN
- Integração de consultas SQL com o Power BI
