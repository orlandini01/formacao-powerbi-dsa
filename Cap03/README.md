# Capítulo 03 — Modelagem, Relacionamentos e DAX

## 📌 Sobre o capítulo
Capítulo considerado um dos mais importantes do curso, focado em modelagem de dados dentro do Power BI e na introdução à linguagem DAX (Data Analysis Expressions). O laboratório prático evolui o dashboard para incluir custo, margem de lucro e indicadores de performance (KPI).

## 🧠 O que eu aprendi
- O que é modelagem de dados e por que ela é essencial em Business Intelligence
- Como aplicar modelagem de dados em projetos de BI
- Diferença entre Query Editor, Report View, Relationship View e Data View
- Como identificar e corrigir relacionamentos incorretos entre tabelas
- Verificação e remoção de duplicidades nos dados
- Detecção automática de relacionamentos no Power BI
- Tipos de cardinalidade entre tabelas: um para muitos (1:*), muitos para um (*:1), um para um (1:1) e muitos para muitos
- Diferença entre Power Query M-Language e DAX, e quando usar cada uma

## 🛠️ Laboratório Prático 2 — Dashboard de Vendas, Custo, Margem de Lucro e KPI
Evolução do dashboard anterior, cobrindo:
- Carregamento de datasets e aplicação de transformações
- Modelagem de dados e verificação/correção de relacionamentos
- Gráfico de cascata (waterfall)
- Gráfico de treemap
- Criação de um indicador chave de performance (KPI)
- Coluna calculada para lucro
- Cálculo da margem de lucro usando DAX
- Versão final do dashboard

## 🎯 Principais conceitos e ferramentas
- Modelagem de dados e relacionamentos (Relationship View)
- Cardinalidade entre tabelas
- DAX: colunas calculadas e medidas (ex: margem de lucro)
- Power Query M-Language (transformações de dados)
- Visuais: cascata (waterfall) e treemap
