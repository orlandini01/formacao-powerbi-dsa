# Capítulo 07 — Power BI Para Análise de Dados de Logística

## 📌 Sobre o capítulo
Capítulo dedicado à área de Logística, com o Mini-Projeto 4: um desafio diferente dos anteriores — em vez de construir um dashboard do zero, o projeto parte de um dashboard já pronto e com problemas, para identificar erros, corrigir a fonte de dados e evoluir a análise.

## 🧠 O que eu aprendi
- Qual a função da área de Logística dentro de uma empresa
- Principais KPIs da área de Logística
- Como identificar erros e problemas em um dashboard já existente no Power BI
- Como alterar a fonte de dados de um projeto Power BI
- Como criar medidas DAX para calcular totais (ex: total de entregas)
- Como aplicar filtro usando medida DAX
- Como configurar classificação de rating (classificação por faixas/estrelas)

## 🛠️ Mini-Projeto 4 — Desconstruindo o Dashboard e Resolvendo Problemas na Área de Logística
Trabalho de correção e evolução do dashboard, cobrindo:
- Identificação de erros e problemas no dashboard (2 partes)
- Alteração da fonte de dados do projeto
- KPI: total de entregas no prazo por canal de entrega
- KPI: percentual de entregas por equipe
- KPI: total de entregas por mês
- Medida para calcular o total de entregas
- KPI: total de entregas por Top 5 vendedores
- KPI: total de entregas com atraso por cidade
- KPI: percentual de entregas por status de entrega
- Configuração de classificação de rating
- Aplicação de filtro com medida DAX
- Versão final do dashboard

## 🎯 Principais conceitos e ferramentas
- KPIs de Logística
- Diagnóstico e correção de problemas em dashboards existentes
- Troca de fonte de dados em um projeto já criado
- DAX aplicado a filtros e totais
- Classificação de rating (ratings visual)
