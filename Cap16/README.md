# Capítulo 16 — Machine Learning e Power BI Para Segmentação de Clientes

## 📌 Sobre o capítulo
Primeiro contato do curso com Machine Learning, integrando Python (via Jupyter Notebook) ao Power BI. O Lab 7 percorre todo o fluxo de um projeto real: da definição do problema de negócio até a publicação do relatório final no Power BI.

## 🧠 O que eu aprendi
- O que é Machine Learning
- O que é Segmentação de Clientes
- Como instalar o Anaconda Python
- Como o Power BI pode ser usado em projetos de Machine Learning
- Como iniciar e trabalhar com o Jupyter Notebook
- Como definir o problema de negócio antes de iniciar um projeto de ML
- Como carregar dados e fazer análise exploratória em Python
- Como fazer pré-processamento de dados para Machine Learning
- Como construir um modelo de Machine Learning para segmentação de clientes
- Como gerar um relatório dos segmentos de clientes com Power BI dentro do Jupyter Notebook
- Como publicar um relatório no Power BI Online (Power BI Service)
- Como editar esse relatório publicado diretamente no Power BI Desktop
